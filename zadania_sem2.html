1. Działania na zbiorach

Polecenie: Wyznacz \(A \cup B\), \(A \cap B\), \(A \setminus B\), \(B \setminus A\), \(A'\), \(B'\), \(B \setminus (A \cap B')\) jeżeli:
a. \(A = \langle -2; 7 \rangle\), \(B = (-\infty; 6\rangle\)
b. \(A = \{x \in \mathbb{R}: |x-1| \ge 3\}\) i \(B = \{x \in \mathbb{R}: x^2-7x+6<0\}\).

a. \(A=[-2,7]\), \(B=(-\infty,6]\).

\(A \cup B = (-\infty, 7]\)
\(A \cap B = [-2, 6]\)
\(A \setminus B = (6, 7]\)
\(B \setminus A = (-\infty, -2)\)
\(A' = (-\infty,-2) \cup (7,\infty)\)
\(B' = (6,\infty)\)
\(A \cap B' = [-2,7]\cap(6,\infty) = (6,7]\), więc \(B\setminus(A\cap B') = (-\infty,6]\setminus(6,7] = (-\infty,6] = B\)

b. Najpierw rozwiązujemy warunki definiujące zbiory:

\(A\): \(|x-1|\ge 3 \Leftrightarrow x-1\ge3 \lor x-1\le-3 \Leftrightarrow x\ge4 \lor x\le-2\), czyli \(A=(-\infty,-2]\cup[4,\infty)\).

\(B\): \(x^2-7x+6<0 \Leftrightarrow (x-1)(x-6)<0\), pierwiastki \(x=1,6\), parabola w górę więc ujemna między pierwiastkami: \(B=(1,6)\).

\(A \cup B = (-\infty,-2] \cup (1,\infty)\)
\(A \cap B = [4,6)\)
\(A \setminus B = (-\infty,-2] \cup [6,\infty)\)
\(B \setminus A = (1,4)\)
\(A' = (-2,4)\)
\(B' = (-\infty,1] \cup [6,\infty)\)
\(A \cap B' = (-\infty,-2]\cup[6,\infty)\), więc \(B\setminus(A\cap B') = (1,6)\setminus[(-\infty,-2]\cup[6,\infty)] = (1,6) = B\)

2. Zbiór wartości funkcji, injekcja, surjekcja, funkcja odwrotna

Polecenie: Dana jest funkcja \(f: \mathbb{R} \to \mathbb{R}\) określona następująco:
a. \(f(x) = x^2+1\)
b. \(f(x) = \begin{cases} x^2 & dla\ x \ge 0 \\ 2x+3 & dla\ x < 0 \end{cases}\)
Wyznacz zbiór wartości funkcji f. Zbadać, czy funkcja f jest injekcją, surjekcją. Wyznacz funkcje odwrotne (jeżeli istnieją).

a. \(f(x)=x^2+1\):

Zbiór wartości: \([1,\infty)\) (minimum w \(x=0\)).
Injekcja: NIE — np. \(f(-1)=f(1)=2\).
Surjekcja na \(\mathbb{R}\): NIE — zbiór wartości \([1,\infty)\ne\mathbb{R}\).
Funkcja odwrotna: nie istnieje dla całej dziedziny \(\mathbb{R}\) (funkcja nie jest różnowartościowa).

b. Dla \(x\ge0\): \(f(x)=x^2\) daje wartości \([0,\infty)\). Dla \(x<0\): \(f(x)=2x+3\) daje wartości \((-\infty,3)\) (bez 3, bo \(x<0\) ściśle). Suma tych zbiorów \([0,\infty)\cup(-\infty,3) = \mathbb{R}\).

Zbiór wartości: \(\mathbb{R}\).
Injekcja: NIE — np. \(f(1)=1\) (z gałęzi \(x^2\)) oraz \(f(-1)=2(-1)+3=1\) (z gałęzi \(2x+3\)), dwa różne argumenty dają tę samą wartość.
Surjekcja na \(\mathbb{R}\): TAK, bo zbiór wartości \(=\mathbb{R}\)=przeciwdziedzina.
Funkcja odwrotna: nie istnieje (funkcja nie jest różnowartościowa, mimo że jest "na").

3. Złożenia funkcji

Polecenie: Określamy trzy funkcje przekształcające zbiór \(\mathbb{R}\) w zbiór \(\mathbb{R}\) w następujący sposób: \(f(x)=x^3-4x\), \(g(x)=\dfrac{1}{x^2+1}\), \(h(x)=x^4\). Znajdź (jeżeli istnieją) a) \(f \circ g \circ h\), b) \(f \circ g\), c) \(h \circ g\).

Wszystkie trzy funkcje mają dziedzinę \(\mathbb{R}\) i zbiory wartości zawarte w \(\mathbb{R}\) (mianownik \(x^2+1\) nigdy nie zeruje się), więc każde złożenie istnieje dla wszystkich \(x\in\mathbb{R}\).

a) \((f\circ g\circ h)(x) = f(g(h(x))) = f\!\left(\dfrac{1}{x^8+1}\right) = \dfrac{1}{(x^8+1)^3} - \dfrac{4}{x^8+1}\), dziedzina \(\mathbb{R}\)

b) \((f\circ g)(x) = f\!\left(\dfrac{1}{x^2+1}\right) = \dfrac{1}{(x^2+1)^3} - \dfrac{4}{x^2+1}\), dziedzina \(\mathbb{R}\)

c) \((h\circ g)(x) = h\!\left(\dfrac{1}{x^2+1}\right) = \dfrac{1}{(x^2+1)^4}\), dziedzina \(\mathbb{R}\)

4. Zbiory spełniania implikacji i równoważności

Polecenie: Wyznaczyć zbiory spełniania implikacji \(\varphi(x) \Rightarrow \psi(x)\) i równoważności \(\varphi(x) \Leftrightarrow \psi(x)\) funkcji zdaniowych \(\varphi(x)\) i \(\psi(x)\): \(\varphi(x): x^2+x+5>0\), \(\psi(x): x+2<0\). Wykorzystaj wzory: \(S(\varphi\Rightarrow\psi)=-S(\varphi)\cup S(\psi)\), \(S(\varphi\Leftrightarrow\psi)=(S(\varphi)\cap S(\psi))\cup(-S(\varphi)\cap-S(\psi))\), gdzie \(-S(\varphi)=Z(\varphi)\setminus S(\varphi)\), \(-S(\psi)=Z(\psi)\setminus S(\psi)\).

\(\varphi(x)\): \(x^2+x+5>0\) — wyróżnik \(\Delta=1-20=-19<0\), więc parabola zawsze dodatnia. \(S(\varphi)=\mathbb{R}\).

\(\psi(x)\): \(x+2<0 \Leftrightarrow x<-2\). \(S(\psi)=(-\infty,-2)\).

\(-S(\varphi) = \mathbb{R}\setminus\mathbb{R} = \varnothing\)

\(-S(\psi) = \mathbb{R}\setminus(-\infty,-2) = [-2,\infty)\)

\(S(\varphi\Rightarrow\psi) = \varnothing \cup (-\infty,-2) = (-\infty,-2)\)
\(S(\varphi\Leftrightarrow\psi) = (\mathbb{R}\cap(-\infty,-2)) \cup (\varnothing\cap[-2,\infty)) = (-\infty,-2)\)
Oba zbiory są identyczne — ponieważ \(\varphi\) jest tautologią (zawsze prawdziwa), implikacja i równoważność z \(\psi\) są prawdziwe dokładnie wtedy, gdy prawdziwe jest \(\psi\).

5. Dowody indukcyjne

Polecenie: Metodą indukcji matematycznej udowodnij:
a. \(\forall n \in \mathbb{N}^+ \left[1^2+2^2+3^2+\cdots+n^2 = \dfrac{n(n+1)(2n+1)}{6}\right]\)
b. \(\forall n \in \mathbb{N} \left[6 \mid (n^3-n)\right]\)

a. Baza indukcji (\(n=1\)): \(L=1^2=1\), \(P=\dfrac{1\cdot2\cdot3}{6}=1\). \(L=P\) ✓.

Krok indukcyjny: zakładamy \(1^2+\cdots+k^2=\dfrac{k(k+1)(2k+1)}{6}\) i pokazujemy dla \(k+1\):

\(1^2+\cdots+k^2+(k+1)^2 = \dfrac{k(k+1)(2k+1)}{6}+(k+1)^2 = (k+1)\left[\dfrac{k(2k+1)}{6}+(k+1)\right] = (k+1)\cdot\dfrac{2k^2+7k+6}{6}\)

Rozkładając \(2k^2+7k+6=(2k+3)(k+2)\), otrzymujemy \(\dfrac{(k+1)(k+2)(2k+3)}{6}\), co jest dokładnie wzorem dla \(n=k+1\) (bo \(2(k+1)+1=2k+3\)). Na mocy zasady indukcji matematycznej wzór zachodzi dla każdego \(n\in\mathbb{N}^+\).

b. Baza indukcji (\(n=0\)): \(0^3-0=0\), a \(6\mid 0\) ✓.

Krok indukcyjny: zakładamy \(6\mid(k^3-k)\), tj. \(k^3-k=6m\) dla pewnego \(m\in\mathbb{Z}\). Dla \(k+1\):

\((k+1)^3-(k+1) = k^3+3k^2+3k+1-k-1 = (k^3-k)+3k^2+3k = 6m+3k(k+1)\)

\(k(k+1)\) to iloczyn dwóch kolejnych liczb całkowitych — zawsze parzysty, więc \(3k(k+1)\) jest podzielne przez 6. Zatem \(6m+3k(k+1)\) też jest podzielne przez 6.

Obie tezy udowodnione metodą indukcji matematycznej (baza + krok indukcyjny).

6. Relacja równoważności i klasy abstrakcji

Polecenie: Dla danego zbioru X oraz relacji \(R\subset X^2\) zbadać, czy R jest relacją równoważności. Jeżeli tak to wyznacz klasy abstrakcji. \(X=\mathbb{N}\), \(xRy \Leftrightarrow 2|(x+y)\).

Zwrotność: \(xRx \Leftrightarrow 2|2x\) — zawsze prawda. ✓
Symetria: \(2|(x+y) \Leftrightarrow 2|(y+x)\) — dodawanie przemienne. ✓
Przechodniość: jeśli \(2|(x+y)\) i \(2|(y+z)\), to ich suma \(x+2y+z\) jest parzysta, a więc \(x+z=(x+2y+z)-2y\) też jest parzyste (odejmujemy liczbę parzystą \(2y\)) — czyli \(2|(x+z)\). ✓

R jest relacją równoważności. Klasy abstrakcji odpowiadają parzystości liczby (suma dwóch liczb jest parzysta wtedy i tylko wtedy, gdy obie są parzyste lub obie nieparzyste):
\([0] = \{0,2,4,6,\dots\}\) — liczby parzyste
\([1] = \{1,3,5,7,\dots\}\) — liczby nieparzyste

9. Aksjomatyczne ujęcie rachunku prawdopodobieństwa

Polecenie: Jak wygląda aksjomatyczne ujęcie rachunku prawdopodobieństwa?

Aksjomaty Kołmogorowa dla przestrzeni probabilistycznej \((\Omega, \mathcal{F}, P)\), gdzie \(\Omega\) to przestrzeń zdarzeń elementarnych, \(\mathcal{F}\) to \(\sigma\)-algebra podzbiorów \(\Omega\) (zdarzenia), a \(P\) to funkcja prawdopodobieństwa spełniająca:
1. \(P(A) \ge 0\) dla każdego \(A \in \mathcal{F}\) (nieujemność)
2. \(P(\Omega) = 1\) (unormowanie)
3. Dla przeliczalnie wielu, parami rozłącznych zdarzeń \(A_1, A_2, \dots\) (\(A_i \cap A_j = \varnothing\) dla \(i \ne j\)): \(P\left(\bigcup_i A_i\right) = \sum_i P(A_i)\) (przeliczalna addytywność)

Z tych trzech aksjomatów wyprowadza się wszystkie pozostałe własności prawdopodobieństwa, np. \(P(\varnothing)=0\), \(P(A')=1-P(A)\), monotoniczność \(P\).

10. Funkcja zdaniowa, zakres zmienności, zbiór spełniania, wykres

Polecenie: Co to jest: funkcja zdaniowa, zakres jej zmienności, zbiór spełniania oraz jej wykres?

Funkcja zdaniowa \(\varphi(x)\) — wyrażenie zawierające zmienną \(x\), które staje się zdaniem logicznym (prawdziwym lub fałszywym) dopiero po podstawieniu za \(x\) konkretnej wartości.
Zakres zmienności \(Z(\varphi)\) — zbiór, z którego wolno podstawiać wartości zmiennej \(x\) (dziedzina funkcji zdaniowej).
Zbiór spełniania \(S(\varphi)\) — podzbiór zakresu zmienności, dla którego funkcja zdaniowa staje się zdaniem prawdziwym: \(S(\varphi)=\{x\in Z(\varphi): \varphi(x)\text{ jest prawdziwe}\}\).
Wykres funkcji zdaniowej — graficzne przedstawienie zbioru spełniania (np. na osi liczbowej lub płaszczyźnie) w postaci zaznaczonych punktów lub przedziałów.

11. Rozdzielność iloczynu kartezjańskiego względem sumy zbiorów

Polecenie: Sprawdź, czy prawdziwa jest następująca równość: \(A \times (B \cup C) = (A \times B) \cup (A \times C)\).

Dowód przez pokazanie równoważności warunków przynależności:

\((x,y)\in A\times(B\cup C) \Leftrightarrow x\in A \land y\in(B\cup C) \Leftrightarrow x\in A \land (y\in B \lor y\in C)\)

\(\Leftrightarrow (x\in A \land y\in B) \lor (x\in A \land y\in C) \Leftrightarrow (x,y)\in A\times B \lor (x,y)\in A\times C \Leftrightarrow (x,y)\in(A\times B)\cup(A\times C)\)

Równość jest PRAWDZIWA — jest to twierdzenie (tożsamość) teorii mnogości, wynikające z rozdzielności koniunkcji względem alternatywy w rachunku zdań.

7. Prawdopodobieństwo geometryczne — spotkanie internautów

Polecenie: Dwoje internautów umówiło się na spotkanie w sieci między godziną 17 a 18, przy czym ze względu na koszty połączenia będą na siebie czekać co najwyżej 10 minut i nie dłużej niż do godziny 18. Jakie jest prawdopodobieństwo tego, że się spotkają?

Niech \(x,y\in[0,60]\) oznaczają momenty przyjścia (w minutach po 17:00) obu osób. Losowa para \((x,y)\) jest punktem losowanym z kwadratu \([0,60]\times[0,60]\) o polu \(3600\). Spotkają się, gdy \(|x-y|\le10\).

Obszar, w którym się NIE spotkają (\(|x-y|>10\)), to dwa trójkąty prostokątne w rogach kwadratu, każdy o przyprostokątnych długości \(60-10=50\), czyli o polu \(\dfrac{50^2}{2}=1250\) każdy — razem \(2500\).

\(P = \dfrac{3600-2500}{3600} = \dfrac{1100}{3600} = \dfrac{11}{36} \approx 0{,}306\)

8. Rozkład dwumianowy — wadliwe zapałki

Polecenie: Badania statystyczne pokazały, że średnio 13,9% zapałek jest wadliwych. Jakie jest prawdopodobieństwo, że w pudełku z 90 zapałkami są więcej niż 2 wadliwe?

Liczba wadliwych zapałek \(X\) ma rozkład dwumianowy \(B(n=90, p=0{,}139)\). Szukamy \(P(X>2)=1-P(X\le2)=1-[P(0)+P(1)+P(2)]\), gdzie \(P(k)=\binom{90}{k}p^k(1-p)^{90-k}\), \(q=1-p=0{,}861\).

\(P(0)=q^{90}\approx 1{,}41\cdot10^{-6}\)
\(P(1)=90\cdot p\cdot q^{89}\approx 2{,}05\cdot10^{-5}\)
\(P(2)=\binom{90}{2}p^2q^{88}\approx 1{,}48\cdot10^{-4}\)
\(P(X\le2)\approx1{,}70\cdot10^{-4}\)
\(P(X>2) \approx 1-1{,}70\cdot10^{-4} \approx 0{,}9998\) (ok. 99,98%)

Wynik ma sens — wartość oczekiwana wynosi \(np=90\cdot0{,}139\approx12{,}5\), więc prawie na pewno wadliwych zapałek będzie więcej niż 2.

12. Prawdopodobieństwo — kto trafi pierwszy

Polecenie: Kuba i Szymon na przemian strzelają piłką do bramki. Kuba trafia do bramki z prawdopodobieństwem 0,6, a Szymon 0,5. Zaczyna Kuba. Oblicz prawdopodobieństwo, że jako pierwszy do bramki trafi Kuba.

Niech \(p_K=0{,}6\), \(p_S=0{,}5\). Kuba trafia pierwszy, jeśli: trafi za pierwszym razem, albo obaj chybią w pierwszej rundzie i Kuba trafi w drugiej, itd. — szereg geometryczny:

\(P = p_K + (1-p_K)(1-p_S)p_K + [(1-p_K)(1-p_S)]^2p_K+\cdots = \dfrac{p_K}{1-(1-p_K)(1-p_S)}\)

\(P = \dfrac{0{,}6}{1-0{,}4\cdot0{,}5} = \dfrac{0{,}6}{0{,}8} = 0{,}75\)

14. Minimalizacja funkcji z tabeli prawdy (metoda K-map)

Polecenie: Na podstawie tabeli prawdy zminimalizuj dowolną metodą funkcję f(a1, a0, b1, b0) dla poszczególnych zmiennych c2, c1 i c0. Wynik zapisz jako sumy iloczynów.

Kluczowa obserwacja: analiza tabeli pokazuje, że traktując \(a_1a_0\) jako liczbę 2-bitową \(A\) oraz \(b_1b_0\) jako liczbę 2-bitową \(B\), wartość \(c_2c_1c_0\) to dokładnie suma \(A+B\) zapisana na 3 bitach (np. dla \(A=3, B=3\): \(3+3=6=110_2\), zgodnie z ostatnim wierszem tabeli). Tabela opisuje więc 2-bitowy sumator binarny — to bardzo ułatwia minimalizację, bo można wykorzystać znaną strukturę sumatora, a wynik zweryfikować mapami Karnaugh.

Niech \(c=a_0b_0\) oznacza przeniesienie z najmłodszego bitu. Po zbudowaniu i uproszczeniu map Karnaugh dla każdej z trzech funkcji otrzymujemy:

\(c_0 = a_0b_0' + a_0'b_0\)

\(c_1 = a_1a_0'b_1' + a_1b_1'b_0' + a_1'a_0'b_1 + a_1'b_1b_0' + a_1'a_0b_1'b_0 + a_1a_0b_1b_0\)
   (równoważnie: \(c_1 = a_1 \oplus b_1 \oplus a_0b_0\) — trzybitowe XOR bitów \(a_1\), \(b_1\) i przeniesienia \(a_0b_0\))

\(c_2 = a_1b_1 + a_1a_0b_0 + a_0b_0b_1\)

Dla \(c_0\) i \(c_2\) mapa Karnaugh daje po 2-3 zgrupowania (w tym jedno "czwórkowe" \(a_1b_1\) dla \(c_2\)), natomiast \(c_1\) — jako funkcja typu XOR trzech "efektywnych" sygnałów — nie daje się uprościć poniżej 6 składników iloczynowych (każdy z nich jest istotnym implikantem pierwszym).

15. Realizacja funkcji z użyciem bramek logicznych

Polecenie: Narysuj z wykorzystaniem bramek logicznych realizację funkcji \(f(w,x,y,z)=xy'z'+wxy'+wx'y+x'yz'+w'x'y'z+w'xyz\) (znak ' oznacza negację).

Funkcja jest już zapisana w postaci sumy iloczynów (SOP), więc realizacja sprowadza się do: dla każdego z 6 składników — bramki NOT na zanegowanych zmiennych oraz jedna bramka AND (3-wejściowa) na cały iloczyn, a następnie jedna bramka OR (6-wejściowa) sumująca wyjścia wszystkich bramek AND.

Schemat układu:
1. Inwertery (NOT): osobne bramki NOT generujące sygnały \(w'\), \(x'\), \(y'\), \(z'\) z sygnałów wejściowych \(w,x,y,z\).
2. Sześć 3-wejściowych bramek AND, po jednej na każdy składnik:
  AND1: \(x, y', z' \to xy'z'\)
  AND2: \(w, x, y' \to wxy'\)
  AND3: \(w, x', y \to wx'y\)
  AND4: \(x', y, z' \to x'yz'\)
  AND5: \(w', x', y', z \to w'x'y'z\)
  AND6: \(w', x, y, z \to w'xyz\)
3. Jedna 6-wejściowa bramka OR łącząca wyjścia AND1–AND6 w sygnał wyjściowy \(f\).

16. Opis działania układów cyfrowych (przerzutniki D)

Polecenie: Opisz działanie poniższych układów (rysunek przedstawia dwa schematy zbudowane z przerzutników typu D).

Lewy układ — 4-bitowy rejestr równoległy (parallel register): cztery przerzutniki D (\(I_0\)–\(I_3\) na wejściach, \(Y_0\)–\(Y_3\) na wyjściach), taktowane wspólnym sygnałem zegarowym (Clock) i sterowane wejściem Load (ładowanie nowej wartości na zboczu zegara) oraz Clear (asynchroniczne zerowanie wszystkich bitów rejestru niezależnie od zegara).

Prawy układ — pamięć rejestrowa (register file) przechowująca 4 słowa 3-bitowe (Słowo 0–3): macierz przerzutników D, w której zapis do wybranego słowa jest sterowany sygnałem "Write enable" oraz liniami wyboru słowa \(S_0, S_1\) (dekodowanie adresu — który z czterech zestawów przerzutników ma przyjąć nowe dane na wejściach Wejście₀–Wejście₂). Odczyt realizowany jest przez bramki AND/OR na wyjściu, działające jak multiplekser wybierający, które z czterech słów ma trafić na wyjścia Wyjście₀–Wyjście₂.

4. Algorytmy i struktury danych

17. Szacowanie złożoności czasowej algorytmów na podstawie pomiarów

Polecenie: Dwa różne algorytmy A₁, A₂ rozwiązują ten sam problem. Zmierzono czas działania tych algorytmów na tym samym komputerze i stwierdzono że: A₁ — 100 danych: ok. 0.01s, 10000 danych: ok. 1s; A₂ — 100 danych: ok. 1s, 10000 danych: ok. 2s. Zakładając że te dane wejściowe są dostatecznie duże, oszacować rząd wielkości funkcji złożoności czasowej obu algorytmów. Na tej podstawie wyciągnąć wniosek odnośnie efektywności algorytmów dla dużej liczby danych wejściowych.

Algorytm A₁: \(n\) rośnie 100-krotnie (\(100\to10000\)), czas też rośnie 100-krotnie (\(0{,}01\to1\)). Jeśli \(T(n)\sim n^k\), to \(100^k=100 \Rightarrow k=1\) — złożoność liniowa \(O(n)\) (sprawdzenie: \(T(n)=0{,}0001\cdot n\); dla \(n=10000\): \(T=1\)s ✓).

Algorytm A₂: \(n\) rośnie 100-krotnie, a czas rośnie tylko 2-krotnie (\(1\to2\)). To charakterystyczne dla złożoności logarytmicznej \(O(\log n)\): jeśli \(T(n)=c\log_{10}n\), to \(c=1/\log_{10}(100)=1/2=0{,}5\); sprawdzenie dla \(n=10000\): \(T=0{,}5\cdot4=2\)s ✓.

A₁ ma złożoność \(O(n)\) (liniową), A₂ ma złożoność \(O(\log n)\) (logarytmiczną).

Mimo że dla małych \(n\) A₂ jest dużo wolniejszy (większa stała/narzut początkowy: 1s vs 0,01s przy \(n=100\)), jego wolniej rosnąca (logarytmiczna) złożoność sprawia, że dla dostatecznie dużych \(n\) A₂ w końcu wyprzedzi A₁ pod względem czasu wykonania. Szacunkowo punkt przecięcia (crossover) wypada gdzieś w okolicach \(n\approx 2\cdot10^4\) (dla \(n=10^5\): \(A_1\approx10\)s, \(A_2\approx2{,}5\)s — A₂ już wyraźnie szybszy). Wniosek: dla dużej liczby danych wejściowych efektywniejszy jest algorytm A₂, mimo gorszej wydajności przy małych danych.

                          18
                /                    \
              9                        28
           /     \                  /       \
          7       13               20        44
        /   \    /   \            /   \     /   \
       3     8  11    15         19    23  35     72
                        \                            \
                        17                            89
Środkowy element całej tablicy (indeks 8) to 18 — korzeń. 19. Wyszukiwanie binarne vs trójdzielne — analiza efektywności

Polecenie: Znajdowanie klucza w tablicy posortowanej przy pomocy algorytmu wyszukiwania binarnego polega na rekurencyjnej procedurze podziału tablicy na dwie części. Próbując poprawić efektywność tego algorytmu zaproponowano podział tablicy na trzy części. Czy ten nowy algorytm będzie bardziej efektywny? Odpowiedź uzasadnić wykonując stosowne obliczenia.

Wyszukiwanie binarne: każdy krok to 1 porównanie i redukcja rozmiaru problemu \(n\) do \(n/2\). Liczba porównań: \(T(n)=\log_2n\).

Wyszukiwanie trójdzielne: każdy krok wymaga 2 porównań (żeby ustalić, w której z 3 części szukać) i redukuje rozmiar problemu do \(n/3\). Liczba porównań: \(T(n)=2\log_3n\).

Porównajmy: \(2\log_3n = \dfrac{2}{\log_2 3}\log_2n \approx \dfrac{2}{1{,}585}\log_2n \approx 1{,}262\cdot\log_2n\)

NIE — algorytm trójdzielny nie będzie bardziej efektywny. Choć redukuje przestrzeń przeszukiwań szybciej (dzieląc przez 3 zamiast przez 2), potrzebuje 2 porównań na krok zamiast 1, a ten narzut przeważa nad korzyścią: wymaga w przybliżeniu o 26% więcej porównań niż klasyczne wyszukiwanie binarne (\(1{,}262 \cdot \log_2 n\) vs \(\log_2 n\)).

21. Dynamiczna tablica łańcuchów wczytywana z pliku

Polecenie: Załóżmy, że w pliku words.txt znajduje się 100 wierszy. Każdy wiersz zawiera jedno niepuste słowo złożone z wielkich liter alfabetu angielskiego. Długość jednego słowa nie przekracza 100 znaków. Napisz program, który odczytuje słowa w pliku i zapisuje je w 100-elementowej tablicy łańcuchów. Tablica powinna być alokowana dynamicznie i nie może zawierać niepotrzebnych elementów tzn. dla każdego słowa powinna być alokowana pamięć tylko taka jak długie jest to słowo (z uwzględnieniem znaku '\0'). Program powinien wyświetlać zawartość tablicy i dealkować pamięć przed jego zamknięciem.

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define N 100
#define MAXLEN 100

int main(void) {
    FILE *f = fopen("words.txt", "r");
    if (!f) { perror("Blad otwarcia pliku"); return 1; }

    char *tab[N];
    char buffer[MAXLEN + 2];
    int i = 0;

    while (i < N && fgets(buffer, sizeof(buffer), f) != NULL) {
        buffer[strcspn(buffer, "\n")] = '\0';       // usuwamy znak nowej linii
        int len = strlen(buffer);
        tab[i] = malloc(len + 1);                    // dokladnie tyle ile potrzeba
        if (!tab[i]) { fprintf(stderr, "Brak pamieci\n"); return 1; }
        strcpy(tab[i], buffer);
        i++;
    }
    fclose(f);

    for (int j = 0; j < i; j++) {
        printf("%s\n", tab[j]);
        free(tab[j]);
    }

    return 0;
}

Kluczowe elementy: malloc(len + 1) alokuje pamięć dokładnie na długość słowa plus bajt na terminator '\0' (bez marnowania pamięci), a każdy element tablicy jest zwalniany funkcją free() przed zakończeniem programu.

27. Skrypt PHP — logowanie/rejestracja do serwisu WWW

Polecenie: Napisz fragment skryptu w PHP odpowiedzialnego za logowanie (lub rejestrację) do serwisu www. Omów problemy z tym związane. Zakładamy, że samo połączenie z bazą zostało zrealizowane poprawnie.

<?php
session_start();

$login = $_POST['login'];
$haslo = $_POST['haslo'];

$stmt = $polaczenie->prepare("SELECT id, haslo_hash FROM uzytkownicy WHERE login = ?");
$stmt->bind_param("s", $login);
$stmt->execute();
$result = $stmt->get_result();

if ($result->num_rows === 1) {
    $wiersz = $result->fetch_assoc();
    if (password_verify($haslo, $wiersz['haslo_hash'])) {
        $_SESSION['user_id'] = $wiersz['id'];
        echo "Zalogowano pomyslnie.";
    } else {
        echo "Nieprawidlowe haslo.";
    }
} else {
    echo "Uzytkownik nie istnieje.";
}
?>
Problemy związane z logowaniem:
— SQL Injection — konieczne użycie zapytań przygotowanych (prepared statements) zamiast wklejania danych użytkownika wprost do zapytania SQL.
— Przechowywanie haseł — nigdy jawnym tekstem, tylko jako hash (password_hash(), algorytm bcrypt), weryfikacja przez password_verify().

— XSS — dane od użytkownika należy filtrować/escapować przy wyświetlaniu.

30. Konwersja sygnału analogowego na cyfrowy

Polecenie: Przedstaw proces zamiany sygnału analogowego na jego reprezentację cyfrową. Jaki jest warunek konieczny wiernego odwzorowania sygnału?

Proces konwersji A/C składa się z trzech etapów:
1. Próbkowanie (sampling) — pobieranie wartości sygnału w regularnych odstępach czasu, z określoną częstotliwością próbkowania \(f_s\)
2. Kwantyzacja (quantization) — przypisanie każdej próbce najbliższej wartości ze skończonego zbioru poziomów (zależnego od rozdzielczości bitowej, np. 16-bit)
3. Kodowanie (encoding) — zapis skwantyzowanych wartości w postaci binarnej

Warunek konieczny wiernego odwzorowania to twierdzenie Nyquista-Shannona: częstotliwość próbkowania musi być co najmniej dwukrotnie większa od najwyższej częstotliwości zawartej w sygnale (\(f_s \ge 2f_{max}\)), inaczej wystąpi aliasing uniemożliwiający poprawne odtworzenie oryginalnego sygnału.
