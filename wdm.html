Wstęp do matematyki

1. Działania na liczbach i zbiorach

Zbiory liczbowe

\(\mathbb{N}\) (naturalne) \(\subset\) \(\mathbb{Z}\) (całkowite) \(\subset\) \(\mathbb{Q}\) (wymierne) \(\subset\) \(\mathbb{R}\) (rzeczywiste) \(\subset\) \(\mathbb{C}\) (zespolone).

Działania na zbiorach

  • suma \(A \cup B\), przecięcie \(A \cap B\), różnica \(A \setminus B\), dopełnienie \(A'\)
  • prawa De Morgana: \((A \cup B)' = A' \cap B'\), \((A \cap B)' = A' \cup B'\)
  • iloczyn kartezjański \(A \times B\) (zbiór par uporządkowanych)
  • \(A \subset B\) (podzbiór), zbiór pusty \(\emptyset\), zbiór potęgowy \(P(A)\)

Przedziały

otwarty \((a,b)\), domknięty \([a,b]\), jednostronnie domknięty \([a,b)\) itd.

Wartość bezwzględna

\(|x|\) — odległość od 0. Własności: \(|a \cdot b| = |a|\cdot|b|\), \(|a+b| \le |a|+|b|\) (nierówność trójkąta).

Potęgi, pierwiastki, logarytmy

  • \(a^m \cdot a^n = a^{m+n}\), \((a^m)^n = a^{mn}\)
  • \(\log_a(xy) = \log_a x + \log_a y\)
  • \(\log_a(x/y) = \log_a x - \log_a y\)
  • \(\log_a x^n = n\log_a x\)

2. Równania i nierówności

Równania liniowe

\(ax + b = 0 \Rightarrow x = -\dfrac{b}{a}\) (dla \(a \ne 0\))

Równania kwadratowe

$$ax^2 + bx + c = 0, \qquad \Delta = b^2 - 4ac$$

  • \(\Delta > 0\): dwa pierwiastki \(x = \dfrac{-b \pm \sqrt{\Delta}}{2a}\)
  • \(\Delta = 0\): jeden pierwiastek \(x = -\dfrac{b}{2a}\)
  • \(\Delta < 0\): brak pierwiastków rzeczywistych

Nierówności

Przy mnożeniu/dzieleniu przez liczbę ujemną — zmiana znaku nierówności!
  • nierówności kwadratowe: szkicujesz parabolę (znak a + miejsca zerowe) i odczytujesz przedziały
  • \(|x| < a \iff -a < x < a\)
  • \(|x| > a \iff x < -a \text{ lub } x > a\)

Układy równań

metoda podstawiania, przeciwnych współczynników, metoda wyznaczników (dla 2x2: \(x = W_x/W\), \(y = W_y/W\))

Równania/nierówności wymierne — pamiętaj o założeniach (mianownik ≠ 0)!

3. Podstawowe własności funkcji

Dziedzina i przeciwdziedzina

dla czego funkcja jest określona / co może zwracać

Monotoniczność

  • rosnąca: \(x_1 < x_2 \Rightarrow f(x_1) < f(x_2)\)
  • malejąca: \(x_1 < x_2 \Rightarrow f(x_1) > f(x_2)\)
  • niemalejąca / nierosnąca — analogicznie z \(\le\) / \(\ge\)

Parzystość / nieparzystość

  • parzysta: \(f(-x) = f(x)\) — symetria względem osi Y
  • nieparzysta: \(f(-x) = -f(x)\) — symetria względem początku układu

Różnowartościowość (iniekcja)

\(x_1 \ne x_2 \Rightarrow f(x_1) \ne f(x_2)\) — każda pozioma prosta przecina wykres maks. raz

Funkcja odwrotna

istnieje tylko gdy f jest różnowartościowa; wykres \(f^{-1}\) to odbicie wykresu f względem prostej \(y = x\)

Funkcja złożona

\((f \circ g)(x) = f(g(x))\) — uwaga na kolejność, zwykle \(f \circ g \ne g \circ f\)

Inne

ograniczoność (z góry / z dołu), okresowość: \(f(x+T) = f(x)\), miejsca zerowe: \(f(x) = 0\), asymptoty (pozioma, pionowa, ukośna)

4. Ciągi liczbowe

Ciąg — funkcja o dziedzinie \(\mathbb{N}\) (\(a_n\), \(n = 1,2,3,\dots\))

Ciąg arytmetyczny

  • różnica: \(r = a_{n+1} - a_n\) (stała)
  • wzór ogólny: \(a_n = a_1 + (n-1)r\)
  • suma n wyrazów: \(S_n = \dfrac{n(a_1+a_n)}{2} = \dfrac{n[2a_1+(n-1)r]}{2}\)

Ciąg geometryczny

  • iloraz: \(q = a_{n+1}/a_n\) (stały)
  • wzór ogólny: \(a_n = a_1 \cdot q^{n-1}\)
  • suma n wyrazów (\(q \ne 1\)): \(S_n = \dfrac{a_1(1-q^n)}{1-q}\)
  • suma nieskończona (\(|q|<1\)): \(S = \dfrac{a_1}{1-q}\)

Ciągi rekurencyjne

  • \(a_{n+1} = a_n + r\) (arytmetyczny w postaci rekurencyjnej)
  • Fibonacci: \(a_1=a_2=1\), \(a_n = a_{n-1} + a_{n-2}\)

Granica ciągu

$$\lim_{n\to\infty} a_n = g$$ jeśli wyrazy zbliżają się dowolnie blisko do g. Ciąg zbieżny/rozbieżny.

Ważne granice: \(\lim (1/n) = 0\), \(\lim q^n = 0\) dla \(|q| < 1\)

Monotoniczność i ograniczoność ciągu

analogicznie jak dla funkcji (\(a_{n+1}\) vs \(a_n\), albo \(a_{n+1} - a_n\))

5. Algebra wektorów

Wektor w \(\mathbb{R}^3\): \(\vec{v} = (x,y,z)\) lub \(\vec{AB} = B - A\) (koniec minus początek)

Działania podstawowe

  • dodawanie: \((x_1,y_1,z_1) + (x_2,y_2,z_2) = (x_1+x_2,\, y_1+y_2,\, z_1+z_2)\)
  • mnożenie przez skalar: \(k\cdot(x,y,z) = (kx,ky,kz)\)
  • długość (norma): \(|\vec{v}| = \sqrt{x^2+y^2+z^2}\)
  • wektor jednostkowy (wersor): \(\vec{v} / |\vec{v}|\)

Iloczyn skalarny (dot product)

$$\vec{a}\cdot\vec{b} = a_x b_x + a_y b_y + a_z b_z = |\vec{a}||\vec{b}|\cos\theta$$

  • wynik to liczba (skalar)
  • \(\vec{a} \perp \vec{b} \iff \vec{a}\cdot\vec{b} = 0\)
  • kąt między wektorami: \(\cos\theta = \dfrac{\vec{a}\cdot\vec{b}}{|\vec{a}||\vec{b}|}\)

Iloczyn wektorowy (cross product) — tylko w \(\mathbb{R}^3\)

wynik to wektor prostopadły do obu wektorów a i b (reguła prawej dłoni na kierunek)

  • \(|\vec{a}\times\vec{b}| = |\vec{a}||\vec{b}|\sin\theta\) = pole równoległoboku rozpiętego na a, b
  • \(\vec{a}\times\vec{b} = \vec{0} \iff\) wektory są równoległe
  • antyprzemienność: \(\vec{a}\times\vec{b} = -(\vec{b}\times\vec{a})\)

Iloczyn mieszany

\((\vec{a}\times\vec{b})\cdot\vec{c}\) = objętość równoległościanu rozpiętego na trzech wektorach

6. Dziedzina funkcji — przykłady

Dziedzina to zbiór argumentów x, dla których wyrażenie ma sens (da się obliczyć).

Funkcja Warunek Przykład
\(\sqrt{f(x)}\) wyrażenie pod pierwiastkiem \(\ge 0\) \(\sqrt{x-3} \to x \ge 3\)
\(1/f(x)\) mianownik \(\ne 0\) \(1/(x-2) \to x \ne 2\)
\(\log_a f(x)\) wyrażenie logarytmowane \(> 0\) \(\log(x+1) \to x > -1\)
\(\sqrt{f(x)}\) w mianowniku wyrażenie pod pierwiastkiem \(> 0\) (ostro, bo dzielenie przez 0 niedozwolone) \(1/\sqrt{x-3} \to x > 3\)
\(\text{tg}(x)\) \(x \ne \pi/2 + k\pi\) —
Gdy w wyrażeniu jest kilka takich "podejrzanych" miejsc naraz (np. pierwiastek i ułamek), warunki się łączy koniunkcją (część wspólna wszystkich warunków, czyli przecięcie zbiorów).

Przykład złożony

Dziedzina \(f(x) = \dfrac{\sqrt{x-1}}{x-4}\):

  • pod pierwiastkiem: \(x-1 \ge 0 \to x \ge 1\)
  • mianownik: \(x-4 \ne 0 \to x \ne 4\)
  • razem: \(D = [1, 4) \cup (4, \infty)\)

7. Wykresy podstawowych funkcji

Liniowa: \(f(x)=ax+b\)

Kwadratowa: \(f(x)=ax^2+bx+c\) (parabola)

Homograficzna: \(f(x)=1/x\)

Wykładnicza: \(f(x)=a^x\) (a>1)

Logarytmiczna: \(f(x)=\log_a(x)\)

Trygonometryczna: \(f(x)=\sin(x)\)

Warto umieć naszkicować te kształty "z pamięci" i wiedzieć, jak zmienia się wykres przy przesunięciach: \(f(x)+c\) (przesunięcie w górę/dół), \(f(x+c)\) (przesunięcie w lewo/prawo), \(-f(x)\) (odbicie względem osi X), \(f(-x)\) (odbicie względem osi Y).

8. Równania wykładnicze i logarytmiczne

Równania wykładnicze

Niewiadoma w wykładniku, np. \(a^x = b\).

  • sprowadzenie do wspólnej podstawy: \(2^x = 8 \to 2^x = 2^3 \to x = 3\)
  • logarytmowanie obu stron, gdy nie da się sprowadzić do wspólnej podstawy: \(3^x = 5 \to x = \log_3 5 = \dfrac{\ln 5}{\ln 3}\)
  • podstawienie pomocnicze: np. \(4^x - 2^{x+1} - 8 = 0\), podstawiamy \(t = 2^x\) (\(t>0\)) \(\to t^2 - 2t - 8 = 0\)

Równania logarytmiczne

Niewiadoma pod logarytmem, np. \(\log_a f(x) = c\).

  • zapis w postaci wykładniczej: \(\log_a x = c \iff x = a^c\)
  • korzystanie z własności logarytmów, żeby zwinąć/rozwinąć wyrażenie do jednego logarytmu
  • zawsze sprawdź założenia i dziedzinę po rozwiązaniu — łatwo o "pierwiastki obce" (rozwiązanie matematycznie poprawne, ale spoza dziedziny)

Przykład

\(\log_2(x) + \log_2(x-2) = 3\), założenie: \(x>0\) i \(x-2>0 \to x>2\)

$$\log_2[x(x-2)] = 3 \Rightarrow x(x-2) = 2^3 = 8 \Rightarrow x^2-2x-8=0 \Rightarrow x=4 \text{ lub } x=-2$$

\(x=-2\) odrzucamy (nie spełnia założenia \(x>2\)) → jedyne rozwiązanie: \(x=4\)

9. Geometria wektorowa: równanie prostej i płaszczyzny

Prosta w \(\mathbb{R}^2\) (na płaszczyźnie)

  • kierunkowa: \(y = ax + b\)
  • ogólna: \(Ax + By + C = 0\)
  • odległość punktu \(P(x_0,y_0)\) od prostej \(Ax+By+C=0\): $$d = \frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}$$

Prosta w \(\mathbb{R}^3\) (przestrzeń)

Prosta określona przez punkt \(P_0=(x_0,y_0,z_0)\) i wektor kierunkowy \(\vec{v}=(a,b,c)\):

  • parametryczna: \(x=x_0+at,\ y=y_0+bt,\ z=z_0+ct\) (\(t \in \mathbb{R}\))
  • kierunkowa (gdy \(a,b,c\ne0\)): \(\dfrac{x-x_0}{a} = \dfrac{y-y_0}{b} = \dfrac{z-z_0}{c}\)

Płaszczyzna w \(\mathbb{R}^3\)

Płaszczyzna określona przez punkt \(P_0=(x_0,y_0,z_0)\) i wektor normalny \(\vec{n}=(A,B,C)\) (prostopadły do płaszczyzny):

  • równanie ogólne: \(A(x-x_0) + B(y-y_0) + C(z-z_0) = 0\), czyli \(Ax+By+Cz+D=0\)
  • wektor normalny można wyznaczyć z iloczynu wektorowego dwóch niewspółliniowych wektorów leżących w płaszczyźnie: \(\vec{n} = \vec{u} \times \vec{v}\)
Typowe zadanie: mając 3 punkty w przestrzeni, wyznacz równanie płaszczyzny — tworzysz dwa wektory z tych punktów, liczysz ich iloczyn wektorowy (to da wektor normalny), a potem podstawiasz jeden z punktów do równania ogólnego.

Kąt i odległość

  • kąt między dwiema prostymi/płaszczyznami — przez iloczyn skalarny wektorów kierunkowych/normalnych
  • prosta równoległa do płaszczyzny \(\iff\) wektor kierunkowy prostej \(\perp\) wektor normalny płaszczyzny (ich iloczyn skalarny = 0)

10. Dokładniejsze warunki dla logarytmów

\(\log_a(x)\) ma sens tylko, gdy spełnione są wszystkie poniższe warunki jednocześnie:

  • \(a > 0\) — podstawa musi być dodatnia
  • \(a \ne 1\) — bo \(\log_1\) nie jest dobrze określony (1 do każdej potęgi to zawsze 1)
  • \(x > 0\) — logarytmować można tylko liczby dodatnie (dziedzina logarytmu to \((0,\infty)\))
To jeden z najczęstszych błędów na egzaminie: przy równaniach/nierównościach logarytmicznych trzeba zapisać założenia dla każdego logarytmu w wyrażeniu osobno (jeśli podstawa też zależy od zmiennej — dodatkowo a>0 i a≠1), a na końcu wziąć część wspólną wszystkich warunków.

Przykład z podstawą zależną od x

\(\log_{x-1}(x+2)\) — założenia: \(x-1>0\) i \(x-1\ne1\) i \(x+2>0\), czyli: \(x>1,\ x\ne2,\ x>-2\) → razem: \(x\in(1,2)\cup(2,\infty)\)

11. Podstawy trygonometrii

Definicje w trójkącie prostokątnym

$$\sin\alpha = \frac{\text{przeciwprostokątna naprzeciw}}{\text{przeciwprostokątna}}, \quad \cos\alpha = \frac{\text{przyprostokątna przy kącie}}{\text{przeciwprostokątna}}$$

$$\text{tg}\,\alpha = \frac{\sin\alpha}{\cos\alpha}, \qquad \text{ctg}\,\alpha = \frac{\cos\alpha}{\sin\alpha} = \frac{1}{\text{tg}\,\alpha}$$

Wartości dla kątów szczególnych

\(\alpha\)0°30°45°60°90°
\(\sin\alpha\)01/2\(\sqrt{2}/2\)\(\sqrt{3}/2\)1
\(\cos\alpha\)1\(\sqrt{3}/2\)\(\sqrt{2}/2\)1/20
\(\text{tg}\,\alpha\)0\(\sqrt{3}/3\)1\(\sqrt{3}\)—

Jedynka trygonometryczna

$$\sin^2\alpha + \cos^2\alpha = 1$$

Wzory redukcyjne (skrót zasady)

Dla kątów postaci \(90°\pm\alpha\), \(180°\pm\alpha\), \(270°\pm\alpha\), \(360°-\alpha\):

  • przy \(90°\) i \(270°\) funkcja "zamienia się" (sin ↔ cos, tg ↔ ctg)
  • przy \(180°\) i \(360°\) funkcja zostaje ta sama (sin zostaje sin, cos zostaje cos)
  • znak wyniku zależy od tego, w której ćwiartce leży kąt wyjściowy \(\alpha\) (przyjmując, że \(\alpha\) jest mały/ostry) — sprawdzasz znak tej samej funkcji w odpowiedniej ćwiartce koła jednostkowego

Przykłady: \(\sin(180°-\alpha) = \sin\alpha\), \(\cos(180°-\alpha) = -\cos\alpha\), \(\sin(90°-\alpha) = \cos\alpha\), \(\sin(-\alpha) = -\sin\alpha\) (sinus jest nieparzysty), \(\cos(-\alpha)=\cos\alpha\) (cosinus jest parzysty)

Wzory sumy i różnicy kątów

$$\sin(\alpha\pm\beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta$$

$$\cos(\alpha\pm\beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta$$

Wzory podwójnego kąta

$$\sin 2\alpha = 2\sin\alpha\cos\alpha$$

$$\cos 2\alpha = \cos^2\alpha - \sin^2\alpha = 2\cos^2\alpha - 1 = 1-2\sin^2\alpha$$

Koło jednostkowe i znaki funkcji

ĆwiartkaZakres kątasincostg
I0°–90°+++
II90°–180°+−−
III180°–270°−−+
IV270°–360°−+−

Okresowość

\(\sin\) i \(\cos\) mają okres \(360°=2\pi\); \(\text{tg}\) i \(\text{ctg}\) mają okres \(180°=\pi\).

Typowe zadanie: znając wartość jednej funkcji trygonometrycznej i ćwiartkę, w której leży kąt, wyznacz wartości pozostałych funkcji (korzystając z jedynki trygonometrycznej i znaków w danej ćwiartce).
