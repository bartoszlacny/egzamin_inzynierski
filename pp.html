Podstawy programowania (C)

1. Typy danych, operatory i wyrażenia

Typy danych

  • całkowite: char, short, int, long, long long (+ warianty unsigned)
  • zmiennoprzecinkowe: float, double, long double
  • char — 1 bajt, kod ASCII, traktowany też jak liczba
  • void — brak typu

Rozmiary (typowo 64-bit): int=4B, float=4B, double=8B — sprawdzasz sizeof().

Operatory

  • arytmetyczne: + - * / % (dzielenie int/int = int! % tylko dla całkowitych)
  • relacyjne: == != < > <= >=
  • logiczne: && || !
  • bitowe: & | ^ ~ << >>
  • przypisania: = += -= *= /= %= itd.
  • inkrementacja/dekrementacja: ++ -- (pre vs post)
  • ternary: warunek ? a : b

Konwersje typów

niejawna (int→float) i jawna / rzutowanie: (int) 3.14

Pułapka: 5/2 = 2, żeby dostać 2.5 trzeba (float)5/2.

2. Instrukcje sterujące

Warunkowe

if (warunek) { ... } else if (...) { ... } else { ... }

switch (zmienna) {
    case 1: ...; break;
    default: ...;
}
Brak break w switch → "przelatywanie" (fall-through).

Iteracyjne

for (init; warunek; krok) { ... }
while (warunek) { ... }
do { ... } while (warunek);   // wykona się min. 1 raz

break — przerywa pętlę/switch. continue — przechodzi do kolejnej iteracji.

Różnica while vs do-while: do-while sprawdza warunek po wykonaniu ciała, więc zawsze wykona się przynajmniej raz.

3. Struktura programu i funkcje

Struktura pliku .c

#include <stdio.h>      // dyrektywy preprocesora
#define MAX 100         // stałe/makra

int suma(int a, int b); // deklaracja (prototyp) funkcji

int main() {            // punkt startowy programu
    ...
    return 0;
}

int suma(int a, int b) { // definicja funkcji
    return a + b;
}

Funkcje

  • deklaracja (prototyp) vs definicja
  • parametry przekazywane przez wartość (kopia) domyślnie; przez wskaźnik, żeby modyfikować oryginał
  • return zwraca wartość i kończy funkcję
  • zmienne lokalne (widoczne w funkcji) vs globalne (widoczne w całym pliku)
  • zasięg (scope) i czas życia zmiennej (lokalna na stosie vs globalna/static)

4. Tablice jednowymiarowe i dwuwymiarowe

1D

int tab[5];                    // deklaracja, wartości niezainicjalizowane
int tab[5] = {1,2,3,4,5};      // inicjalizacja
int tab[] = {1,2,3};           // rozmiar wywnioskowany

Indeksowanie od 0. Brak sprawdzania granic w C — wyjście poza tablicę to niezdefiniowane zachowanie (UB).

2D (macierze)

int m[3][4];               // 3 wiersze, 4 kolumny
int m[2][2] = {{1,2},{3,4}};

for (int i = 0; i < 3; i++)
    for (int j = 0; j < 4; j++)
        m[i][j] = i*4+j;

W pamięci tablica 2D jest ułożona wierszami (row-major order) — jeden ciągły blok pamięci.

Tablica jako argument funkcji jest przekazywana jako wskaźnik na pierwszy element (traci info o rozmiarze — trzeba przekazać rozmiar osobno).

5. Wskaźniki — podstawy

int x = 10;
int *p = &x;    // p przechowuje adres x
printf("%d", *p); // *p = "wartość spod adresu" = 10
*p = 20;        // zmienia x na 20
  • & — operator adresu ("adres zmiennej")
  • * — operator dereferencji ("wartość spod wskaźnika")
  • wskaźnik NULL — nie wskazuje nigdzie, warto sprawdzać przed użyciem

Parametry funkcji typu wskaźnikowego

pozwalają modyfikować oryginalną zmienną (bo C przekazuje domyślnie przez wartość):

void zwieksz(int *p) {
    (*p)++;
}
int main() {
    int a = 5;
    zwieksz(&a);   // a = 6
}

To symulacja przekazania przez referencję w C — klasyczne pytanie: różnica przekazania przez wartość vs przez wskaźnik.

6. Związek wskaźników i tablic

Nazwa tablicy to (w większości kontekstów) adres jej pierwszego elementu — tab ≈ &tab[0].

int tab[5] = {1,2,3,4,5};
int *p = tab;        // p wskazuje na tab[0]
printf("%d", *(p+2)); // to samo co tab[2]

Arytmetyka wskaźników

  • p+1 przesuwa się o sizeof(typ) bajtów, nie o 1 bajt
  • *(p+i) ≡ p[i] ≡ tab[i]
  • różnica dwóch wskaźników do elementów tej samej tablicy = liczba elementów między nimi

Różnica tablica vs wskaźnik: tablica ma zarezerwowaną, stałą pamięć (nie da się jej "przestawić"), wskaźnik można przestawiać na dowolny adres.

Napisy (stringi)

w C to tablice char zakończone '\0':

char napis[] = "abc";  // {'a','b','c','\0'}
char *p = "abc";

7. Rekurencja

Funkcja wywołuje samą siebie. Musi mieć:

  1. przypadek bazowy (warunek stopu) — bez niego nieskończona rekurencja → przepełnienie stosu (stack overflow)
  2. przypadek rekurencyjny — wywołanie z "mniejszym" problemem, zbliżające do bazy

Przykład — silnia

int silnia(int n) {
    if (n <= 1) return 1;       // przypadek bazowy
    return n * silnia(n - 1);   // przypadek rekurencyjny
}

Przykład — Fibonacci

int fib(int n) {
    if (n <= 1) return n;
    return fib(n-1) + fib(n-2);
}

Warto umieć narysować drzewo wywołań (np. dla fib) i pokazać jak stos wywołań się buduje i zwija.

Rekurencja vs iteracja: rekurencja czytelniejsza dla problemów "z natury rekurencyjnych" (drzewa, dziel i zwyciężaj), ale kosztuje pamięć stosu i zwykle jest wolniejsza od pętli.

8. Dynamiczna alokacja pamięci

Pamięć przydzielana w czasie działania programu (na stercie), gdy nie znamy rozmiaru z góry (np. w czasie kompilacji).

Funkcje z <stdlib.h>

int *p = malloc(5 * sizeof(int));   // 5 nieinicjalizowanych intów
int *q = calloc(5, sizeof(int));    // 5 intów wyzerowanych
p = realloc(p, 10 * sizeof(int));   // zmiana rozmiaru (zachowuje dane)
free(p);                            // zwolnienie pamięci
  • malloc — nie zeruje pamięci; calloc — zeruje
  • realloc może przenieść blok w inne miejsce pamięci (zwraca nowy adres!)
  • zawsze sprawdzaj, czy malloc/calloc nie zwróciło NULL (brak pamięci)
Klasyczne błędy: wyciek pamięci (memory leak) — zapomniane free(); dangling pointer — użycie wskaźnika po free(); double free — dwukrotne zwolnienie tego samego bloku.

Dobra praktyka: po free(p) ustawić p = NULL;, żeby przypadkowo nie użyć go ponownie.

9. Operacje na plikach

Otwieranie i zamykanie

FILE *f = fopen("dane.txt", "r");
if (f == NULL) { /* błąd otwarcia */ }
...
fclose(f);

Tryby otwarcia

  • "r" — odczyt (plik musi istnieć)
  • "w" — zapis (nadpisuje / tworzy nowy plik)
  • "a" — dopisywanie na końcu pliku
  • "r+", "w+", "a+" — odczyt i zapis jednocześnie
  • dodanie b (np. "rb") — tryb binarny

Funkcje odczytu/zapisu

fprintf(f, "%d %s", liczba, napis);   // zapis sformatowany
fscanf(f, "%d", &liczba);             // odczyt sformatowany

fputc('a', f);   fgetc(f);            // pojedynczy znak
fputs("tekst", f);   fgets(bufor, rozmiar, f);   // linia tekstu

fwrite(tab, sizeof(int), n, f);       // zapis binarny
fread(tab, sizeof(int), n, f);        // odczyt binarny
Zawsze sprawdzaj wynik fopen (może zwrócić NULL) i pamiętaj o fclose — inaczej dane mogą nie zostać zapisane na dysk (bufor).

feof(f) — sprawdza, czy osiągnięto koniec pliku.

10. Struktury

Definicja

struct Punkt {
    int x;
    int y;
};

struct Punkt p1 = {1, 2};
p1.x = 5;              // dostęp przez kropkę

Struktury a wskaźniki

struct Punkt *wp = &p1;
wp->x = 10;            // strzałka = (*wp).x, skrót dostępu przez wskaźnik

typedef

typedef struct {
    int x;
    int y;
} Punkt;

Punkt p2 = {3, 4};     // nie trzeba pisać "struct Punkt"
  • struktury mogą zawierać inne struktury, tablice, wskaźniki
  • tablice struktur: struct Punkt tab[10];
  • struktury jako parametry funkcji — domyślnie kopiowane przez wartość (dla dużych struktur lepiej przekazywać wskaźnik)

11. Stos vs sterta

Stos (stack) Sterta (heap)
zmienne lokalne, parametry funkcji pamięć z malloc/calloc/realloc
automatycznie zarządzany (alokacja/zwolnienie przy wejściu/wyjściu z funkcji) zarządzany ręcznie przez programistę (free)
szybki dostęp, ograniczony rozmiar wolniejszy, dużo większy rozmiar
przepełnienie: stack overflow (np. zbyt głęboka rekurencja) problem: wycieki pamięci, fragmentacja
Klasyczne pytanie: co się stanie, gdy zwrócisz z funkcji wskaźnik do zmiennej lokalnej (na stosie)? → błąd, bo pamięć jest zwalniana po wyjściu z funkcji (dangling pointer).

12. const i static

const

const int MAX = 100;   // nie można zmienić wartości po inicjalizacji

void f(const int *p) {  // funkcja nie może zmienić wartości spod wskaźnika
    // *p = 5;  // błąd kompilacji
}
  • const int *p — wskaźnik na stałą (nie można zmienić wartości, można zmienić adres)
  • int *const p — stały wskaźnik (nie można zmienić adresu, można zmienić wartość)

static

znaczenie zależy od kontekstu:

  • zmienna lokalna w funkcji — zachowuje wartość między wywołaniami (inicjalizowana tylko raz, żyje przez cały czas trwania programu, ale widoczna tylko w funkcji)
  • zmienna/funkcja globalna — widoczna tylko w danym pliku (ogranicza zasięg, ukrywa przed innymi plikami .c)
void licz() {
    static int wywolania = 0;   // zapamiętuje wartość między wywołaniami
    wywolania++;
    printf("%d\n", wywolania);
}
// kolejne wywołania licz(): 1, 2, 3, ...
Częste pytanie egzaminacyjne: różnica między zmienną lokalną zwykłą a static lokalną — ta druga nie jest tworzona na nowo przy każdym wywołaniu funkcji.

13. Unie i enumeracje

Unia (union)

Wszystkie pola dzielą to samo miejsce w pamięci — rozmiar unii to rozmiar jej największego pola, a nie suma rozmiarów (jak w strukturze).

union Dane {
    int i;
    float f;
    char c[4];
};

union Dane d;
d.i = 65;
printf("%d", d.i);   // 65
printf("%c", d.c[0]); // 'A' (bo w little-endian bajt 65 znajduje się na pierwszej pozycji)
Zapisanie wartości do jednego pola i odczytanie przez inne pole daje dostęp do tych samych bajtów w pamięci, interpretowanych jako inny typ — używane np. do reinterpretacji bitów (float ↔ int) albo do oszczędzania pamięci, gdy tylko jedno pole jest używane naraz.

Struktura vs unia — różnica rozmiaru

struct S { int a; float b; };   // sizeof(S) = 8 (4+4), pola obok siebie
union  U { int a; float b; };   // sizeof(U) = 4, pola nakładają się

Enumeracja (enum)

Nazwany zbiór stałych całkowitych — poprawia czytelność kodu (nazwy zamiast "magicznych liczb").

enum Dzien { PON, WT, SR, CZW, PT, SOB, NIEDZ };
// domyślnie: PON=0, WT=1, SR=2, ... kolejne wartości

enum Dzien d = SR;
if (d == SR) printf("Środa\n");
  • można nadać własne wartości startowe: enum { A=10, B, C }; → A=10, B=11, C=12 (kolejne rosną od ostatniej)
  • w C wartości enum to w praktyce zwykłe int — kompilator nie sprawdza, czy przypisujesz "poprawną" wartość z enuma

14. Wskaźniki do funkcji

Wskaźnik może przechowywać adres funkcji, a nie tylko adres zmiennej — pozwala przekazywać funkcje jako parametry lub wybierać funkcję do wywołania w czasie działania programu.

Deklaracja i użycie

int dodaj(int a, int b) { return a + b; }
int odejmij(int a, int b) { return a - b; }

int (*operacja)(int, int);   // wskaźnik na funkcję o sygnaturze int f(int,int)

operacja = dodaj;
printf("%d", operacja(2, 3));   // 5

operacja = odejmij;
printf("%d", operacja(5, 3));   // 2
Nawiasy wokół *operacja są konieczne — int *operacja(int, int) (bez nawiasu) to zupełnie inna deklaracja: funkcja zwracająca int*, a nie wskaźnik na funkcję.

Typowe zastosowanie — funkcja jako parametr

int wykonaj(int (*f)(int, int), int a, int b) {
    return f(a, b);
}

wykonaj(dodaj, 3, 4);     // 7
wykonaj(odejmij, 3, 4);   // -1

To mechanizm pozwalający np. przekazać funkcję porównującą do qsort(), albo zbudować tablicę wskaźników do funkcji (dyspozytor operacji na podstawie indeksu/znaku).

Tablica wskaźników do funkcji

int (*tab[2])(int, int) = { dodaj, odejmij };
printf("%d", tab[0](2, 3));  // 5

15. Dyrektywy preprocesora

Preprocesor przetwarza kod przed kompilacją — operuje na tekście źródłowym, nie zna typów ani składni C.

Proste makra (stałe)

#define MAX 100
#define PI 3.14159

int tab[MAX];   // podczas preprocesingu MAX zamienia się na 100

Makra z parametrami (makro-funkcje)

#define KWADRAT(x) ((x)*(x))
#define MAX2(a,b) ((a) > (b) ? (a) : (b))

int y = KWADRAT(5);      // rozwija się do ((5)*(5)) = 25
int m = MAX2(3, 7);      // ((3) > (7) ? (3) : (7)) = 7
Zawsze otaczaj parametry makra nawiasami! #define KWADRAT(x) x*x dla KWADRAT(2+3) rozwinie się do 2+3*2+3 = 11, a nie do 25 — klasyczna pułapka na egzaminie.

Kompilacja warunkowa

#ifdef DEBUG
    printf("Tryb debugowania\n");
#endif

#ifndef MAX
    #define MAX 100
#endif

#if VERSION >= 2
    // kod tylko dla wersji 2 i wyższych
#else
    // kod dla starszych wersji
#endif
  • #ifdef X — kompiluj blok, jeśli X jest zdefiniowany (dowolnie, nawet bez wartości)
  • #ifndef X — kompiluj blok, jeśli X nie jest zdefiniowany (częste przy strażnikach nagłówków, patrz niżej)
  • #undef X — usuwa definicję makra

Strażnik nagłówka (include guard)

#ifndef MOJPLIK_H
#define MOJPLIK_H

// zawartość pliku nagłówkowego .h

#endif

Zapobiega wielokrotnemu dołączeniu tego samego pliku nagłówkowego (co powodowałoby błąd redefinicji przy wielu #include).

Inne dyrektywy

  • #include — dołącza zawartość innego pliku (<plik> — biblioteki systemowe, "plik" — pliki własne)
  • #pragma — dyrektywy specyficzne dla kompilatora (np. #pragma once — nowocześniejsza alternatywa dla strażnika nagłówka)
